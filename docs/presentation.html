BROWSER-TAB SHARING

Reads the page.
Never acts alone.

  • You choose to share a Chrome or Edge tab, explicitly
  • Lumen answers questions about the shared page
  • No clicks, no form submits, no navigation without your approval
  • Generated HTML runs in a sandbox

Human in the loop

Manifest V3 extension plus screen capture feed page context to the server. Every action stays behind an approval prompt.
