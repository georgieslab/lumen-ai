PRODUCT CASE STUDY

One companion.
More ways to think.

Lumen brings voice, vision, research, and user-chosen browser context into one conversational workspace—so the next question can start wherever curiosity does.

01 / The challenge

Bring useful capabilities together without breaking the flow.

Voice, files, research, and personal context each add value—but they can make an assistant feel like a collection of disconnected tools. Lumen's design challenge is to keep one conversational thread while making each capability easy to understand and optional to use.

A guiding principle
Context should be invited, not assumed.
02 / The experience

One conversation, many ways in.

The conversation is the home base. People can start with a question, bring an image or document, switch to voice, or ask Lumen to research a topic—without moving to a separate tool.

01 — ASK

Speak or type

Use a text conversation or browser speech recognition. Configured AWS Transcribe and Polly services provide optional speech input and neural voice output.

02 — BRING CONTEXT

Share what matters

Attach an image or PDF, or explicitly share the active browser tab with the read-only extension. Lumen receives context the person chose to provide.

03 — GO DEEPER

Explore and create

Request sourced web research, glance at live weather or cryptocurrency cards, and turn a response into a downloadable PDF.

✦

Personal, not prescriptive. Response tone and style are adjustable; signed-in users can inspect, edit, pause, or delete saved memory.

03 / Browser context

Share a page.
Keep control.

The browser extension makes page context opt-in. It reads a single snapshot only after the user clicks Share this tab—never by silently watching open pages.

01 · Choose

The user opens the extension on the active tab and grants access to the Lumen origin.

02 · Share

Lumen receives selected text, or visible page text if nothing is selected. The snapshot is capped at 20,000 characters; form values are excluded.

03 · Stop

A sharing indicator stays visible while context is active. The user can stop sharing, and must share again to refresh the snapshot.

READ-ONLY BY DESIGN · NO CLICKS, TYPING, OR NAVIGATION
04 / The system

A focused stack, built to connect.

A React and Vite client talks to an Express API. The server centralizes AI-provider access, live-data tools, auth, memory, and document generation.

05 / What shipped

A connected product, not a pile of demos.

The result is a single assistant surface with distinct capabilities that can be brought into the conversation when they are useful.

  • 01Multimodal conversation across text, voice, images, and PDFs.
  • 02Research and live data alongside regular conversation.
  • 03User-managed personalization with editable profile and memory controls.
  • 04Explicit browser sharing that adds page context without granting action control.
  • 05An installable web app for supported mobile browsers.
A note on outcomes
